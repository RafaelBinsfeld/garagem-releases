# Garagem: versões

Aqui ficam as versões prontas do **Garagem**, o app para controlar gastos,
consumo, manutenções e documentos de motos e carros. O código-fonte é
privado; este repositório tem só os instaladores.

Baixe na página [Releases](https://github.com/RafaelBinsfeld/garagem-releases/releases/latest):

| Arquivo | Para |
|---|---|
| `Garagem-X.Y.Z-arm64.apk` | Android (celulares atuais). Instale por cima da versão anterior: os dados continuam. |
| `Garagem-X.Y.Z-armeabi-v7a.apk` | Android antigo (32 bits). |
| `Garagem-X.Y.Z-windows.zip` | Windows: extraia e dê dois cliques em `Instalar.cmd`. |

O app avisa quando sai uma versão nova (Configurações › Atualizações). Para
isso ele só consulta esta página, uma vez por dia, sem enviar nenhum dado.
